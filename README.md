## Sobre mí

Estudio el **Grado en Diseño Multimedia y Gráfico** y me muevo entre el diseño y el código:
me gusta que las cosas se vean bien **y** que funcionen bien. Construyo webs, webapps y
herramientas internas para empresas reales, desde la maqueta hasta la base de datos.

- Estudiando **Diseño Multimedia y Gráfico**
- Desarrollando webs, un **CRM** y un **portal de clientes** para empresas
- Ahora mismo: herramientas a medida con **Supabase** y automatizaciones con **n8n**
- Aprendiendo: arquitectura de aplicaciones, bases de datos y flujos con IA
- Abierto a colaborar en proyectos web y de automatización
